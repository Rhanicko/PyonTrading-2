# Pre-trade discipline

Treat this as a review artifact, not a broker gate. Require a written plan, evidence source, risk inputs, news state, strategy version and explicit unknowns before stating that a candidate is ready for human review.

If any required item is missing, report `REVIEW_REQUIRED`. Do not transmit orders, create an execution instruction or imply that an automated approval is permission to trade.
