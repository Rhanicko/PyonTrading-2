# Performance review

Base every observation on recorded candidates, fills and versioned tests. Identify missing evidence before proposing an experiment. Describe potential changes as hypotheses requiring out-of-sample validation, not as learned profitability.

Never change strategy parameters solely because of one outcome and never rewrite prior journal evidence.
